# Pomodoro Timer

[View the project requirements](https://roadmap.sh/projects/pomodoro-timer)

In this project, we create a Pomodoro timer application using React.

The application includes:

* A focused work timer
* Short and long break timers
* Controls for starting, pausing, and resetting the timer
* Automatic switching between work and break sessions
* A clear countdown display
* Session progress tracking
* Visual feedback for the active timer mode
* A responsive and accessible interface

React manages the countdown, tracks the current session, updates the displayed time, and controls transitions between focus and break periods.

The goal of this project is to practise React fundamentals: state, effects, timers/intervals, conditional logic, and the development of a practical productivity tool.

## Status

🚧 In progress. This folder currently contains only the React + Vite scaffold — no timer functionality has been implemented yet.

## Tech Stack

* React + React DOM
* Vite
* Tailwind CSS (via the repository's shared stylesheet)

## Running Locally

From the repository root, after `npm install`:

```bash
npm run dev:28
```

Or from within this folder:

```bash
cd 28-pomodoro-timer
npm run dev
```
