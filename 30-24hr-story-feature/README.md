# 24hr Story Feature

[View the project requirements](https://roadmap.sh/projects/stories-feature)

In this project, we create a client-side social-media stories feature using React.

The application includes:

* A collection of user stories
* Story preview thumbnails
* A full-screen story viewer
* Automatic progression between story items
* Manual navigation to previous and next stories
* Visual progress indicators
* Support for images and other story content
* Viewed and unviewed story states
* Temporary story availability based on a 24-hour lifespan
* A responsive and accessible interface

React manages the story data, tracks the active story, controls playback and navigation, updates progress indicators, and determines whether a story is still available based on its creation time.

The goal of this project is to practise React fundamentals: state management, effects, timers, conditional rendering, and the development of a complex interactive frontend feature.

## Status

🚧 In progress. This folder currently contains only the React + Vite scaffold — no story-feature functionality has been implemented yet.

## Tech Stack

* React + React DOM
* Vite
* Tailwind CSS (via the repository's shared stylesheet)

## Running Locally

From the repository root, after `npm install`:

```bash
npm run dev:30
```

Or from within this folder:

```bash
cd 30-24hr-story-feature
npm run dev
```
